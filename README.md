# C-friendlist

C 언어로 구현한 콘솔 기반 친구 목록 관리 프로그램입니다. 친구의 이름, 나이, 전화번호를 입력해 텍스트 파일에 저장하고, 저장된 친구 목록을 확인할 수 있습니다.

> 현재 버전: `v0824`

## 주요 기능

프로그램을 실행하면 다음 메뉴가 표시됩니다.

```text
1. 친구 목록 보기
2. 새 친구 저장
3. 친구 삭제 하기
4. 끝내기
```

### 1. 친구 목록 보기

저장 파일에 기록된 친구 정보를 한 줄씩 읽어 화면에 출력합니다.

- 목록에 번호를 붙여 출력
- 저장 파일이 없으면 파일을 새로 생성
- 저장된 친구가 없으면 빈 목록 안내 메시지 출력

### 2. 새 친구 저장

사용자로부터 다음 정보를 입력받아 친구 목록 파일에 추가합니다.

- 이름
- 나이
- 전화번호

입력된 정보는 탭(`\t`)으로 구분되어 한 줄 단위로 저장됩니다.

예시:

```text
홍길동    20    010-1234-5678
```

### 3. 친구 삭제 하기

메뉴 항목은 구현되어 있으나, 현재 버전에서는 삭제 기능의 실제 동작이 아직 작성되지 않았습니다.

### 4. 끝내기

프로그램을 종료합니다.

## 저장 방식

친구 정보는 텍스트 파일에 저장됩니다.

```c
char* fname = "d://data//list.txt";
```

현재 저장 경로는 `D:\data\list.txt`로 고정되어 있습니다. 따라서 프로그램을 실행하기 전에 `D:\data` 폴더가 존재하는지 확인해야 합니다. 폴더가 없으면 직접 생성해야 합니다.

## 사용된 C 언어 요소

- `struct`를 이용한 친구 정보 구조체 정의
- `FILE` 포인터를 이용한 파일 입출력
- `fopen`, `fgets`, `fputs`, `fclose` 사용
- 파일 열기 모드 `r`, `a`, `w` 사용
- 문자열 처리를 위한 `strcat`
- 함수 분리를 통한 메뉴·조회·추가·삭제 기능 구성
- `switch` 문을 이용한 메뉴 선택 처리

친구 정보는 다음 구조체에 저장됩니다.

```c
struct address {
    char name[30];
    char age[5];
    char phone[15];
};
```

## 실행 방법

### Visual Studio에서 실행하기

1. 저장소를 클론하거나 ZIP 파일로 다운로드합니다.
2. Visual Studio에서 `v0824.vcxproj`를 엽니다.
3. 솔루션 탐색기에서 `v0824.c`를 확인합니다.
4. `D:\data` 폴더를 생성합니다.
5. `Ctrl + F5` 또는 `디버깅하지 않고 시작`을 선택합니다.
6. 메뉴 번호를 입력해 기능을 사용합니다.

### Git으로 다운로드하기

```bash
git clone https://github.com/skgmny/C-friendlist.git
cd C-friendlist
```

## 현재 확인된 제한 사항

- 친구 삭제 함수 `delete_list()`는 현재 비어 있습니다.
- 저장 경로가 `D:\data\list.txt`로 고정되어 있어 다른 환경에서는 경로 수정이 필요합니다.
- 현재 코드는 `gets()`를 사용하고 있습니다. `gets()`는 입력 길이 제한이 없어 버퍼 오버플로 위험이 있으므로, 실제 개선 버전에서는 `fgets()` 사용을 권장합니다.
- 이름, 나이, 전화번호에 대한 입력 검증이 아직 없습니다.
- `getche()`를 사용하므로 Windows 환경 및 해당 함수가 제공되는 개발 환경이 필요합니다.
- C 파일을 Visual Studio 프로젝트에 포함하고 있지만 프로젝트 설정에는 C++20이 지정되어 있습니다. C 언어 프로젝트로 명확히 관리하려면 컴파일 설정을 점검할 필요가 있습니다.
