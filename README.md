# C-Friendlist

C 언어 학습 과정에서 제작 중인 **콘솔 기반 친구 목록 관리 프로그램**입니다.

친구의 이름, 나이, 전화번호를 입력해 텍스트 파일에 저장하고, 저장된 친구 목록을 조회하는 기능을 구현하고 있습니다.

> ⚠️ **개발 중인 프로젝트입니다.**  

## 프로젝트 상태

| 기능 | 상태 |
|---|---|
| 메뉴 출력 | 구현 완료 |
| 친구 목록 조회 | 기본 기능 구현 |
| 새 친구 저장 | 기본 기능 구현 |
| 친구 삭제 | 구현 예정 |
| 입력값 검증 | 구현 예정 |
| 친구 정보 수정 | 구현 예정 |
| 친구 검색 | 구현 예정 |

## 현재 메뉴

```text
1. 친구 목록 보기
2. 새 친구 저장
3. 친구 삭제 하기
4. 끝내기
```

## 기능 설명

### 1. 친구 목록 보기

저장 파일에 기록된 친구 정보를 읽어 화면에 출력합니다.

- 친구 목록에 번호를 붙여 출력합니다.
- 저장 파일이 없으면 파일을 생성합니다.
- 저장된 친구가 없으면 빈 목록 안내 메시지를 출력합니다.

### 2. 새 친구 저장

사용자로부터 다음 정보를 입력받아 친구 목록 파일에 추가합니다.

- 이름
- 나이
- 전화번호

입력된 정보는 탭(`\t`)으로 구분되어 한 줄 단위로 저장됩니다.

```text
홍길동    20    010-1234-5678
```

### 3. 친구 삭제 하기

현재 메뉴에는 포함되어 있지만, 삭제 기능의 실제 동작은 아직 구현되지 않았습니다.

### 4. 끝내기

프로그램을 종료합니다.


## 현재 제한 사항

- 친구 삭제 함수 `delete_list()`는 아직 실제 로직이 구현되지 않았습니다.
- 저장 경로가 `D:\data\list.txt`로 고정되어 있어 다른 환경에서는 경로 수정이 필요합니다.
- 입력값에 대한 길이 및 형식 검증이 아직 없습니다.
- 입력 처리와 파일 열기 실패에 대한 예외 처리가 충분하지 않습니다.
- 향후 안전한 입력 함수와 오류 처리를 적용할 예정입니다.

## 향후 개선 계획

- 친구 삭제 기능 구현
- 친구 정보 수정 기능 추가
- 이름 또는 전화번호 검색 기능 추가
- 입력값 길이 및 형식 검증
- 안전한 입력 함수 적용
- 저장 파일 경로를 상대 경로 또는 사용자 입력 방식으로 변경
- 파일 열기 실패 및 잘못된 입력에 대한 오류 처리 강화
- 친구 정보를 보다 체계적인 형식으로 관리
